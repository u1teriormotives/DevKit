# Security Policy

## Supported Versions

Currently, the beta version of this CLI is supported; it is stable, but unfinished.

| Version      | Supported          |
| ------------ | ------------------ |
| 0.2.0-beta   | :white_check_mark: |

## Reporting a Vulnerability

If you happen to encounter a vulnerability in the code, please [report it to iaastius](mailto:m@u1t.dev)
or to [the main reporting email](mailto:reporting@u1t.dev).
